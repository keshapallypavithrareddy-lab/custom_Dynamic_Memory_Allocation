# Custom Dynamic Memory Allocation in C

## Project Description
This project implements a custom dynamic memory allocator in C. It demonstrates how memory blocks can be allocated, freed, and reused.

## Features
- Custom memory allocation
- Memory block management using metadata
- Reuse of previously freed memory blocks
- Management of multiple memory blocks

## Technologies Used
- C programming language
- GCC compiler
- Git and GitHub
- Linux/Ubuntu terminal

## How to Compile
```bash
gcc main.c -o main
```

## How to Run
```bash
./main
```

## Test Cases
1. Test memory allocation.
2. Test reuse of a freed memory block.
3. Test allocation of multiple blocks.
